# DineDesk – Restaurant Website

## About
DineDesk is a responsive restaurant website built using HTML, CSS, and JavaScript. Users can explore food items, search the menu, add food to their cart, try a demo checkout, and make a table reservation.

## Features
- Food menu with images and prices
- Search food items
- Add and remove cart items
- Cart total calculation
- Demo checkout with UPI, Card, and Cash on Delivery options
- Table reservation form
- Responsive design for mobile and desktop
- Attractive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.

## Note
Payment and reservation features are for demonstration purposes only.
